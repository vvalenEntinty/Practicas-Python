## Requisitos

- Python 3.13.x
- Jupyter Notebook

## Instalación

1. Clonar el repositorio:
    git clone <url-de-tu-repo>

2. Instalar Jupyter:
    pip install jupyter

## Ejecución

1. Abrir una terminal en la carpeta `Practica_2`
2. Ejecutar:
    jupyter notebook

3. En el navegador, navegar a `notebooks/ejercicio10.ipynb`
4. Ejecutar todas las celdas con **Kernel → Restart & Run All**

## Ejercicio 10 - Competencia de cocina

Simula una competencia de cocina con 5 participantes evaluados por 3 jueces en 5 rondas.
Muestra la tabla de posiciones luego de cada ronda y una tabla final con:
- Puntaje total acumulado
- Rondas ganadas
- Mejor puntaje en una ronda
- Promedio por ronda
